# Chem-AI-toolkit-Molecules
An interactive practice tool for Year 11 Chemistry students (ACT BSSS Chemistry T, Unit 2: Molecules).

A student practice tool for verifying AI-generated chemistry: Lewis structures, VSEPR shapes, polarity, intermolecular forces and net ionic equations. Built for Year 11 Chemistry.

Part of a digital teaching portfolio. Built as a single self-contained HTML file.
